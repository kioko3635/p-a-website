# Proctor & Allan website

1. Extract the ZIP on your computer.
2. Upload the contents of this folder into the ROOT of your GitHub repository (do not upload the ZIP itself).
3. In the repository, open Settings > Pages.
4. Select Deploy from a branch, main, /(root), then Save.
5. Share the github.io link shown by GitHub Pages after deployment.

Use a public repository for GitHub Free. Existing files with the same name should be replaced. If GitHub limits the number of files per upload, upload the assets folder first, then the remaining folders and files in a second commit. Include .nojekyll (a hidden file). No build tools are required. This export works at the domain root or under a repository subfolder.

The contact forms retain FormSubmit. Each receiving inbox must have activated the service; delivery has not been verified.
